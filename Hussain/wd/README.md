# Shaikh Hussain — Portfolio

A responsive personal portfolio for Shaikh Hussain, a B.Tech Cyber Security student, web developer, and community leader in Surat, Gujarat.

## Portfolio sections

- About and focus areas
- Experience and leadership
- Skills, tools, and languages
- Four selected projects: CodeBridge Consultancy, Secure Password Manager, Personal Portfolio Website, and AI-Powered Web Development
- Education and certifications
- Contact details and email-draft form

## Built with

- HTML
- CSS
- Vanilla JavaScript

The site is static and has no build step or backend. The contact form validates its fields and opens a prefilled email draft; it does not send or store messages.

## Run locally

Open `index.html` in a browser, or open this folder in VS Code and use Live Server.
