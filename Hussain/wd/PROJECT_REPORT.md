## Implementation

- Semantic HTML page sections and accessible navigation
- Responsive CSS layout with no profile photo
- Resume image available from view and download links
- Vanilla JavaScript for the mobile menu, scroll reveals, year, contact validation, and email draft
- No build process, backend, database, or published project links required

## Contact form behavior

The browser validates the form and prepares a message addressed to `sh5899016@gmail.com` in the visitor's email application. It does not send or store the message.

## Local use

Open `index.html` in a browser or serve this folder with VS Code Live Server.

## Publishing

This folder can be published as a static site, such as with GitHub Pages. Add the final public site URL to `sitemap.xml` after deployment.
